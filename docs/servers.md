# 连接媒体服务器

在「设置 → 服务器」添加服务器，填写名称和连接信息。可以先点「测试连接」检查访问，测试不会写入本机配置；点「保存」才会保存。添加多台服务器后，可在设置中切换，也可从媒体库的服务器选择器切换。

保存后，打开「媒体库」选择分库，或输入影片、剧集名称搜索当前服务器。使用 Jellyfin 或 Emby 时，点「筛选」按钮展开搜索框和筛选条件；飞牛影视和绿联影视的搜索框直接显示。

## Jellyfin / Emby

1. 选择 **Jellyfin** 或 **Emby**。地址可包含端口和反向代理子路径；Emby 地址末尾带 `/emby` 也可以。可直接输入完整的 HTTP/HTTPS 地址；不填协议时，「安全连接」开关决定使用 HTTPS 还是 HTTP。
2. 输入用户名和密码。普通媒体库账号即可，不需要管理员权限。无密码账号可留空。Jellyfin 也可在「认证方式」中选择「API 密钥」并填写密钥；已有的 API 密钥配置无需迁移。
3. 保存后即可浏览该账号有权访问的媒体库。Emby Connect、直播以及需要额外打开或关闭流程的动态媒体源暂不支持。

**重新登录：** 会话过期时，编辑原有服务器，重新输入密码并保存。只改显示名称、密码留空时保留现有会话；修改地址或用户名需要重新登录。切换 Jellyfin 的认证方式会清除旧方式的凭据，并建立新的本地配置身份。如果升级后旧版单独存储的 Emby 会话未恢复，请重新登录。

**实际验证：** 普通账号已通过 Docker 上的 Jellyfin 12.4.0 和 Emby 4.9.3.0 联调，覆盖浏览、原生播放、字幕和进度同步等。复现步骤和具体结果：[Jellyfin 环境](../tool/jellyfin-test/README.md) · [Jellyfin 结果](../tool/jellyfin-test/RESULTS.md)；[Emby 环境](../tool/emby-test/README.md) · [Emby 结果](../tool/emby-test/RESULTS.md)。

## 飞牛影视

选择「飞牛影视」，填入实际用于打开飞牛影视的地址（包括所需的端口或反代子路径）、用户名和密码。可先测试片库访问，再保存。会话过期后，编辑原配置重新登录。仅在受信任的局域网使用 HTTP；其他网络请使用 HTTPS。

适配参考 [fnmovie](third-party-notices.md#fnmovie)。本地模拟服务测试覆盖鉴权、图片、HTTP Range 拖动和进度回读；不同飞牛影视版本、反代与 FN Connect 尚无真机兼容性验证记录。专项测试在仓库根目录运行：

```sh
fvm flutter test test/fnmovie_client_test.dart test/fnmovie_settings_test.dart
```

要额外验证真实 libmpv 拖动，可随测试传入 `--dart-define=FNMOVIE_NATIVE_FIXTURE=/path/to/video.mp4`，指向 [Emby 联调环境](../tool/emby-test/README.md)中的 Big Buck Bunny MP4 的绝对路径。

## 绿联影视

1. 按[绿联官方指南](https://support.ugnas.com/detail/article/zh-CN/908)，在 UGOS Pro 的「影视中心 → 设置 → 媒体服务器」启用服务，配置有密码的专用媒体库账号。不要使用 NAS 管理员账号，也不要把空密码服务暴露到公网。
2. 选择「绿联影视」，填写 NAS 主机名或 IP。仅支持 HTTPS，默认端口为 `9443`；如使用其他端口须明确填写。不要添加 `/emby` 或其他路径。
3. 使用系统信任的证书时，「证书 SHA-256 指纹」可留空。使用自签名证书时，点击「获取指纹」查看服务器当前提供的指纹（不会发送登录信息）。通过 NAS 或可信局域网独立核对后，再点击「填入指纹」。不要仅凭未知公网连接显示的指纹信任该证书；更换证书后须重新核对。
4. 输入专用账号，测试连接并保存。会话失效后，编辑原配置重新登录。

Sakuga 直接使用 NAS 已有片库；首页轮播从有封面或横幅的电影和剧集中在本地随机选取，优先使用有横幅的条目。续播不回写服务器，不支持收藏。绿联影视中心不是完整的 Emby 服务器，兼容性可能随 UGOS Pro 固件变化。

可选[真机联调](../integration_test/ugreen_server_test.dart)：准备未纳入版本控制、仅用于测试的 JSON 文件。设置 `UGREEN_LIVE_TEST` 为 `true`，填写 `UGREEN_TEST_URL`、`UGREEN_TEST_USERNAME`，按需填写 `UGREEN_TEST_PASSWORD` 与 `UGREEN_TEST_FINGERPRINT`。可用 `UGREEN_TEST_SERIES` 指定剧集搜索词。测试片库需有带海报的电影，以及带剧集及季的海报和背景，以及分集缩略图的可播放剧集。不要分发包含这些参数的测试包。

```sh
fvm flutter test integration_test/ugreen_server_test.dart -d DEVICE_ID \
  --dart-define-from-file=/path/to/local-ugreen-test.json
```

## 备份与迁移

在「设置 → 服务器」标题栏的「⋯」菜单选择「导出配置」或「导入配置」。桌面端可选择保存位置，Android 通过系统分享菜单保存或发送 JSON 文件。

- **默认不导出凭据。** 导入后可编辑配置重新登录或补填 API 密钥。只有勾选「包含登录凭据」才会导出明文登录令牌或密钥，务必妥善保管。账号密码不会保存到本机，也不会导出；登录令牌和 API 密钥保存在本机的应用偏好设置中，删除配置会移除对应的本机凭据。
- **只追加，不覆盖。** 导入时先预览新增和重复项；按服务器类型、规范化地址、认证方式及用户名判定重复，名称不参与判定。导入不会切换已选中的服务器；若原来没有服务器，列表首项成为当前服务器。
- 服务器配置备份不包含仅保存在本机的播放进度。
